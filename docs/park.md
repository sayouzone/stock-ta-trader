

4가지 선정 방법에서 확인 요소들이 상당 부분 정량화 가능

| 선정 방법 | 정량화 가능 요소 | 정량화 어려운 요소 |
|:---|:---|:---|
| 강세/연속상승 | 신고가, 매물대 돌파, 거래량 증감, 등락폭, 지지/저항 | 시장 호재, 테마 형성 |
| 약세/연속하락 | 신저가, 반등 매물대, 거래량, 하향 추세, 저항 하향돌파 | 시장 약세 이유 |
| 시장 재료 | 강세 섹터(상대강도) | 호재 발표, 테마 형성 |
| 차트 | 지지/저항, 추세, 패턴 | 패턴 해석의 주관성 |


| 구분 | 정량화 가능 요소 | 핵심 데이터 |
|:---|:---|:---|
| 순간 체결량 검색 | 체결량 급증, 가격 급변, 전일 대비 거래량 급증, 상대강도 | 실시간 틱/체결 |
| 가격·거래량 급변 검색식 | 가격 급등락, 거래량 급변, 사용자 검색식 | 분봉 + 검색조건 |
| 시장 재료(지수 연동) | 지수 움직임/멈춤, 베타계수, 강세 종목 | 지수 + 종목 분봉 |
| 공시·뉴스 기반 | (속보 트리거) | 공시/뉴스 피드 |

## 시트 → 코드 매핑

####

| 시트의 선정 방법 | 구현 클래스 | 확인 요소 정량화 |
| :--- | :--- | :--- |
| 최근일 강세/연속 상승 | StrongMomentumScreener | 신고가, 매물대 돌파, 거래량, 추세 유지, 지지/저항, 정배열 패턴 + 호재/테마(주입) |
| 최근일 약세/연속 하락 | WeakReversalScreener | 신저가, 연속하락, 투매 거래량, 장중 반등(아래꼬리), 반등 매물대 여력 |
| 시장 재료(테마/섹터) | MarketThemeScreener | 테마/호재(주입), 섹터 상대강도, 상투 경계(과열 감점) |
| 차트(지지/저항/추세/패턴) | ChartPatternScreener | 20일선 기울기, 지지선 근접, 저항 돌파 임박, 변동성 수축 패턴 |

####

| 시트의 장중 선정 방법 | 구현 클래스 | 핵심 정량화 |
| :--- | :--- | :--- |
| 순간 체결량 검색 | TickSurgeScreener | 체결량 급증 배율, 가격 급변, 전일 동시각 대비 거래량, 상승+급증 동조 |
| 가격/거래량 급변 검색식 | PriceVolumeScanScreener | 가격 급등락, 거래량 급변, 검색식 적중(주입), 분봉 모멘텀 보강 |
| 시장 재료(지수 연동) | IndexLinkedScreener | 지수 변동성, 베타계수, 지수 동조, 베타 보정 상대강도(지수 초과분) |
| 공시/시황/속보/뉴스 | NewsFlashScreener | 속보 발생(주입), 즉각적 체결 반응, 가격 반응 명확성 |
